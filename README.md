# Artificial Intelligence for Modular Radar Systems

OSSIE is ann Open Source Software Defined Radio Platform. PySOSA is a python module for building SOSA based RDF graphs. REDHAWK is a software-defined radio (SDR) framework. (REOS) Radar and ElectroOptical Simulation Framework. ANTARES is an open-source, high-performance simulation platform for naval radar operations. RadarSimPy is a powerful Python library for radar transceiver modeling, baseband simulation from point targets and 3D meshes, and advanced signal processing. The Neural Radar Development Kit (NRDK) is an open-source and MIT-licensed Python library and framework for developing, training, and evaluating machine learning models on radar spectrum and multimodal sensor data. NEC2++ is a C++ rewrite of the Numerical Electromagnetics Code (NEC-2). Xnec2c is a high-performance multi-threaded electromagnetic simulation. xnec2c-optimize is an optimization framework to tune antenna geometries. Elmer is a tool that can solve a large number of partial differential equations making it an ideal tool for multiphysical problems. DOLFINx is the computational environment of FEniCSx. Palace, for PArallel LArge-scale Computational Electromagnetics, is an open-source, parallel finite element code for full-wave 3D electromagnetic simulations. Meep is a free and open-source software package for electromagnetics simulation. gprMax is an open source software that simulates electromagnetic wave propagation. Bempp-cl is an open-source boundary element method library that can be used to assemble all the standard integral kernels for Laplace, Helmholtz, modified Helmholtz, and Maxwell problems. OpenParEM is a free and open-source frequency-domain full-wave electromagnetic simulator. openEMS is a free and open electromagnetic field solver. Puma-EM provides surface Method of Moments for Electromagnetics

The directory structure includes a specific folder for each phase of development and engineering programs:

- __MBSE__: The root folder Arcadia (ARChitecture Analysis and Design Integrated Approach) is a method of tools dedicated to systems engineering and architecture, supported by the Capella modeling tool.    
  - __CAD__: For computer-aided design.
  - __CAM__: Dedicated to the part manufacturing and assembly process.
  - __CAS__: For simulation of end-to-end functionality and performance analysis.
