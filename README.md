# Artificial Intelligence for Modular Radar Systems Simulation

REDHAWK is a software-defined radio (SDR) framework. ANTARES is an open-source, high-performance simulation platform for naval radar operations. RadarSimPy is a powerful Python library for radar transceiver modeling, baseband simulation from point targets and 3D meshes, and advanced signal processing. The Neural Radar Development Kit (NRDK) is an open-source and MIT-licensed Python library and framework for developing, training, and evaluating machine learning models on radar spectrum and multimodal sensor data. NEC2++ is a C++ rewrite of the Numerical Electromagnetics Code (NEC-2). Xnec2c is a high-performance multi-threaded electromagnetic simulation. xnec2c-optimize is an optimization framework to tune antenna geometries. Elmer is a tool that can solve a large number of partial differential equations making it an ideal tool for multiphysical problems. DOLFINx is the computational environment of FEniCSx. Palace, for PArallel LArge-scale Computational Electromagnetics, is an open-source, parallel finite element code for full-wave 3D electromagnetic simulations. Meep is a free and open-source software package for electromagnetics simulation. gprMax is an open source software that simulates electromagnetic wave propagation. Bempp-cl is an open-source boundary element method library that can be used to assemble all the standard integral kernels for Laplace, Helmholtz, modified Helmholtz, and Maxwell problems. OpenParEM is a free and open-source frequency-domain full-wave electromagnetic simulator. openEMS is a free and open electromagnetic field solver. Puma-EM provides surface Method of Moments for Electromagnetics
